# RAG 知识库问答 · 简介

## 这是什么

一个检索增强生成（RAG）的知识库问答应用：你上传文档，系统把文档切分成小块并转成向量，
提问时先检索最相关的片段，再让大模型**只依据这些片段**回答，并标注来源文件名。

## 主要能力

- 混合检索：dense（向量相似度）+ 关键词匹配双路召回，再做文件级去重
- 多厂商模型：对话与嵌入各自支持多档案，可切换到 OpenAI 兼容 / 本地 Ollama 等
- 增量导入：按内容哈希去重，重复导入秒过；支持删除已移除文件与全量重建
- 流式问答：回答逐个字返回，可随时停止，保留已生成内容
- 访客隔离：公开演示模式下每位访客有独立目录与向量集合，仅自己可见

## 怎么用

1. 在「导入」页上传或勾选文件，点击「批量导入所选」
2. 等进度完成（首次会调用嵌入模型）
3. 回到「对话」页提问，例如「这个项目支持哪些功能？」
4. 回答下方可展开来源片段，核对依据

## 数据说明

- 只读样例对所有访客开放；访客上传的内容只对自己可见
- 超过 7 天未访问的访客数据会自动清理
